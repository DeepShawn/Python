# Python Nexus v0.2.0

全平台离线 Python 学习与开发系统：集 Python 学习、编程、运行、交互调试、习题、考试、流程图与积木编程于一体。

## 下载

| 平台 | 文件 | 说明 |
| --- | --- | --- |
| Windows 10 / 11 | `Python Nexus_0.2.0_x64-setup.exe`（推荐）或 `.msi` | 内置嵌入式 CPython 3.12（含 requests、beautifulsoup4、PyInstaller），无需另装 Python，完全离线 |
| Android 7+ | `PythonNexus-android.apk` | WebView + Pyodide 离线运行时（arm64 / armv7） |
| 任意浏览器 | `python-nexus-web.zip` | 解压后用任意静态服务器打开，例如 `python -m http.server`；也可直接访问 GitHub Pages 在线版 |

> 安装包未经代码签名证书签名：Windows SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可；Android 需允许「安装未知来源应用」。

## 主要功能

- **IDE**：CodeMirror 6 编辑器（字符串和注释中不弹出补全）、多文件项目、终止死循环、编译检查（字节码）、unittest
- **IDLE 式 Shell**：程序输出、`input()` 与 `>>>` 在同一个控制台中；程序结束后可继续使用其中的变量
- **可视化执行**：按真实执行顺序逐行回放，变量变化、调用栈、断点、0.25×–4× 速度，流程图同步高亮
- **流程图**：代码自动生成流程图，导出 SVG / PNG / Mermaid；函数调用图、模块导入图、类继承图
- **三种风格**：普通 · 科幻 · 黑客，带音效与动态特效
- **学习**：8 个阶段 52 个可运行课时，含离线爬虫（内置教学网站 `http://nexus.local`）、自动化、数据处理与项目实战
- **习题**：36 道题、11 种题型（随机参数、代码填空、调试、算法步数限制、结构 / 流程图、模块设计等），Argon2id 答案保护，题库 Ed25519 签名
- **考试**：限时试卷、断点续考、自动交卷、成绩记录
- **积木编程**：Blockly 中文积木实时生成 Python
- **Windows 专属**：打开 / 保存本地项目文件夹、本机 HTTP 教学网站、离线安装 `.whl`、一键打包为 EXE

## 已知限制

- 科学计算库（NumPy、pandas、Matplotlib）未包含在网页版与 Android 版中；Windows 版可通过「离线安装第三方库」导入 `.whl`。
- Android 版暂不支持原生 CPython（Chaquopy），第三方库支持范围小于 Windows 版。
- 离线环境下答案保护只能提高读取成本，不能保证绝对不可逆向。
